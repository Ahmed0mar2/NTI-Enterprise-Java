# NTI Enterprise Java

Training projects and labs covering core Java, Maven, Spring, Spring MVC, AOP, and JPA.

## Projects

- `NTI-Day1` - Java fundamentals and object-oriented programming
- `NTI_Day2` to `NTI_Day7` - Java exercises covering collections, streams, lambdas, threading, records, generics, and Maven
- `AOP` - JDK dynamic proxy and AOP concepts
- `spring-annotations` - Spring component scanning, dependency injection, profiles, scopes, and notifications
- `TaskMVC` - Spring MVC task management application
- `springmvc-four-components` and `springmvc-plumbing-demo` - Spring MVC configuration and request-processing examples
- `spring-bean-lifecycle-xml` - XML-based Spring bean lifecycle example
- `Library_Management_System_SpringJPA` - JPA entity relationships, inheritance, fetching, cascading, and JPQL/Criteria queries
- `customer-api`, `demo`, and `Veloci` - additional Spring and Java practice projects

## Running a Maven project

From a project directory:

```bash
mvn clean package
```

Use the project-specific README files for any additional setup or database configuration. Build output, IDE metadata, compiled classes, and local environment files are excluded through the root `.gitignore`.
